# 什么是 MiniJAM？

MiniJAM 是受 JAM 执行模型启发的独立实验性网络和工程项目，用于在完整 JAM 网络可用前开发、运行和观察服务。

MiniJAM 关注从服务代码到 Refine、Work Report、独立验证、Accumulate 和状态变化的可运行路径。它不等同于 JAM 主网，也不宣称完整实现 JAM 协议。

请参阅 [MiniJAM 与 JAM](./minijam-and-jam.md) 了解边界。
