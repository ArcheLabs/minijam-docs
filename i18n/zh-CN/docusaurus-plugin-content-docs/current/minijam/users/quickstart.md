# 用户快速开始

体验 MiniJAM 的最快方式是使用托管的 Playground。公共 Playground 尚未提供时，获得完整 release bundle 和匹配凭据的 Operator 可以通过 Docker 运行完整 Stage 0 release。

外部用户当前无法仅使用公开源码独立构建完整 MiniJAM Stack。

- 使用托管 Playground：**尚未公开提供**
- 运行 Stage 0 release：[使用 Docker 运行 MiniJAM](../operators/docker-deployment.md)

Playground 上线后，可使用它提交服务操作，并查看从 Refine 到 Accumulate 的执行历史。不要将 `127.0.0.1` 视为公共 Playground 地址。
