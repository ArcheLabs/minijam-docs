# 用户快速开始

公开用户入口是基于镜像的本地开发 bundle，不需要 Stage 0 凭据。

外部用户当前无法仅使用公开源码独立构建完整 MiniJAM Stack。

- 使用托管 Playground：**尚未公开提供**
- 本地运行：[使用 Docker 在本地运行 MiniJAM](../operators/local-docker.md)

Playground 上线后，可使用它提交服务操作，并查看从 Refine 到 Accumulate 的执行历史。不要将 `127.0.0.1` 视为公共 Playground 地址。
