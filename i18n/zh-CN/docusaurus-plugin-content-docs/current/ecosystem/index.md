# MINI 生态

MINI 是 MiniJAM 项目的一等组成部分：它是围绕网络、应用、建设者、用户和公共物品形成的生态与经济层。

技术层与经济层被有意分开。

~~~text
MiniJAM
  网络 / 执行 / 共识边界

JamScript
  应用开发边界

MINI 生态
  启动 / 激励 / 市场 / 公共物品 / 治理
~~~

这并不意味着 MINI 变得次要。它让契约更加清楚：经济机制可以通过实验和治理继续演化，而不会悄悄改变 MiniJamSpec 或 JamScript application ABI。

## 当前文档

- [激励协议](./incentive-protocol.md) — 项目市场、排放、流动性与公共物品激励。
- [MINI 代币经济学](./tokenomics.md) — 当前关于分配、启动、流动性与长期网络经济的草案。

它们的状态应与 MiniJAM Stage-1 或 JamScript release 的技术稳定性分开理解。

MiniJAM 与 JamScript 提供技术底座，MINI 则为“什么值得建设、如何持续建设”提供经济与协调层。
