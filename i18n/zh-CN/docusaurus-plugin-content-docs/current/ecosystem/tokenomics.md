# MINI 代币经济学

MINI 是 MiniJAM 网络和激励协议的基础资产。MINI 的初期任务是完成网络与生态启动，并在未来逐步过渡到由网络通胀、手续费和质押共同维护安全的长期经济模型。

:::warning 治理草案

本文是 MINI 代币经济学草案。

公平分发、MINI Lucky 和前期运营储备将在启动前确定。MINI 持有者将通过治理，对 Root 市场启动、三年激励排放、基金会预算和长期网络经济模型进行正式表决。

:::

MINI 初始供应分配如下：

| 用途 | 比例 |
| --- | --- |
| 公平分发 | 1% |
| MINI Lucky | 1% |
| 前期运营储备 | 1% |
| Root 市场启动 | 约 33.55% |
| 初始流动性 | 约 18.45% |
| 激励协议 | 35% |
| 基金会 | 10% |

MINI 不设置创始人、顾问、私募或投资人份额。

## 初始供应

MINI 的初始供应总量为：

> **1,000,000,000 MINI**

初始供应用于 MINI 启动、流动性、激励协议和基金会。

MiniJAM 主网上线后，可能根据网络安全需要引入新的通胀机制。具体通胀率和分配方式不包含在初始代币经济学中，由 MINI 持有者通过治理决定。

## 公平分发

采用绑定曲线积累流动性是一种较为常用的启动机制，但前期参与者的优势过大，对于 MINI 来说并不合适。另外，绑定曲线通常具有特定的市值毕业阈值。在缺少前期价格发现的情况下，可能导致流动性池与市场参与度不匹配，并加剧市场操纵行为。

MINI 通过前期公平分发机制，确保更多用户能够公平参与，并形成早期价格发现。

初始供应的 1% 通过 MINI Genesis 公平分发。每个区块释放固定额度的 MINI，直到全部释放完毕。参与者投入 DOT 后，可以持续获得后续所有区块中相应份额的 MINI。

公平分发结束后，协议计算最大有效持仓成本 (p_0)，并将其作为 Root 曲线的起始价格。

公平分发获得的 MINI 将在流动性池建立时同步 Claim。

## MINI Lucky

初始供应的 1% 用于 MINI Lucky。MINI Lucky 用于扩大早期持有人范围，使 MINI 不完全按照投入金额分配。

具体机制是通过 Polkadot App 形成的可信社交网络进行分配。同样地，MINI Lucky 分发的 MINI 将在流动性池建立时同步 Claim。

## 前期运营储备

初始供应的 1% 作为前期运营储备，由团队用于：

- 市场运营；
- 社区活动；
- 生态合作；
- 内容和品牌建设；
- 基础设施及其他上线支出。

这部分 MINI 不属于团队成员的个人分配，由公开的运营金库持有。所有使用记录应保持透明，并定期向社区报告余额、支出对象和资金用途。

## Root 市场启动

初始供应的约 33.55% 通过 Root 曲线出售。

Root 曲线从公平分发形成的 (p_0) 开始，最高上涨至 (10p_0)：

```text
P(q)=p_0(1+9q/Q)
```

其中：

- (Q) 是 Root 计划出售的 MINI；
- (q) 是当前已经售出的 MINI；
- (p_0) 是公平分发形成的起始价格。

在这条曲线中，早期参与者承担更高的不确定性，因此能够获得更低的价格。

## 初始流动性

初始供应的约 18.45% 专门用于建立 MINI/DOT 流动性。Root 曲线募集的 DOT 本金与流动性储备中的 MINI 配对，使公开市场的初始价格与曲线最终价格保持一致。

初始 LP 由协议国库持有，不属于团队或基金会的可支配资产，也不用于日常运营支出。

## 激励协议

初始供应的 35% 用于激励协议，并在三年内完成释放：

| 阶段 | 占 MINI 总供应 |
| --- | --- |
| 第一年 | 20% |
| 第二年 | 10% |
| 第三年 | 5% |
| 三年以后 | 0% |

三年后，创世激励排放将停止。激励协议将继续通过交易手续费、子协议手续费和其他协议收入运行。

## 基金会

初始供应的 10% 分配给基金会，用于：

- 协议审计；
- 法律和合规；
- 长期基础设施；
- 安全响应；
- 生态合作；
- 公共事务。

基金会份额不属于团队个人。

## 长期网络经济模型

MiniJAM 主网上线后，将逐步转向独立的网络安全经济模型，包括：

- 验证者或 Worker 质押；
- 网络手续费；
- 节点奖励；
- 恶意行为罚没。

该模型不包含在初始代币经济学中，需要根据 MiniJAM 和 JAM 的实际进展，由 MINI 持有者通过治理决定。
