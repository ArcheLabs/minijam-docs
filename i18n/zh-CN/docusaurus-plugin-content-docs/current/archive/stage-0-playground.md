# Stage-0 Playground 归档

Stage-0 使用浏览器优先的 Playground、C/C++ 示例、钱包控制的 Service 部署以及早期多进程本地 Stack。

这个环境对验证最初 MiniJAM 执行路径很重要，但已经不是当前推荐开发架构。

应用开发请使用 [JamScript](../jamscript/index.md)，当前支持网络请使用 [MiniJAM Stage-1](../minijam/network/stage-1.md)，本地集成请阅读[本地运行 MiniJAM](../minijam/developers/local-docker.md)。

旧 API 参考仍保留在 [Playground API](../minijam/developers/playground-api.md)。

不要把 Stage-0 的 controller、wallet、compiler 或 deployment 假设当作 Stage-1 契约。
