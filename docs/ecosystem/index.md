# MINI Ecosystem

MINI is a first-class part of the MiniJAM project: the ecosystem and economic layer around the network, applications, builders, users, and public goods.

The technical and economic layers are intentionally separated.

~~~text
MiniJAM
  network / execution / consensus boundary

JamScript
  application development boundary

MINI ecosystem
  launch / incentives / markets / public goods / governance
~~~

This does **not** make MINI secondary. It makes the contract clearer: economic mechanisms can evolve through experimentation and governance without silently changing MiniJamSpec or the JamScript application ABI.

## Current documents

- [Incentive Protocol](./incentive-protocol.md) — project markets, emissions, liquidity, and public-goods incentives.
- [MINI Tokenomics](./tokenomics.md) — the current draft for allocation, launch, liquidity, and long-term network economics.

Their status should be read independently from the technical stability of MiniJAM Stage-1 or JamScript releases.

MiniJAM and JamScript provide the technical substrate; MINI provides an economic and coordination layer around what gets built and sustained.
