# Incentive Protocol

The Incentive Protocol is planned as a protocol for funding, launching, and incentivizing open projects.

It is intended for open-source teams, contributors, and ecosystem participants who need transparent ways to coordinate support. Its relationship with MiniJAM is complementary: MiniJAM provides an execution and service-development environment, while the Incentive Protocol is concerned with project funding and incentives.

**Current status: Planned.** Future documentation may cover the model, participation flows, governance, and implementation boundaries. Final economic parameters, contract addresses, deployed networks, audit status, and reward rules have not been established here.
