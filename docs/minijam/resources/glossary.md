# Glossary

- **Service**: An application execution unit.
- **PVM**: The execution target for service programs.
- **Refine**: The computation stage that processes declared work inputs.
- **Accumulate**: The state transition stage that applies accepted results.
- **Work Report**: A description of computation and its result.
- **HostCall**: A controlled request from a service to its host runtime.
