# JAM and MiniJAM Resources

This page collects common resources for learning JAM, developing services, and using MiniJAM.

## JAM Specifications and Documentation

* [Gray Paper](https://graypaper.com/graypaper.pdf)
  The formal definition of the JAM protocol.

* [Polkadot Wiki: JAM Chain](https://wiki.polkadot.com/learn/learn-jam-chain/)
  Introductory material for JAM concepts and architecture.

* [JAM Docs](https://docs.jamcha.in/)
  Community-maintained documentation for JAM implementations and development.

* [JAM Test Vectors](https://github.com/w3f/jamtestvectors)
  Protocol test vectors published by Web3 Foundation.

## JAM Resource Indexes

* [Awesome JAM](https://github.com/DrEverr/Awesome-JAM)
  A community-maintained list of JAM resources, SDKs, tools, examples, tutorials, and articles.

* [JAM Improvement Proposals](https://github.com/polkadot-fellows/JIPs)
  Interface conventions, tooling conventions, and improvement proposals for JAM.

* [Polkadot Forum: JAM](https://forum.polkadot.network/tag/jam)
  JAM design, implementation, and ecosystem discussions.

## Fluffy Labs Tools

* [Fluffy Labs](https://fluffylabs.dev/)
  Entry point for Fluffy Labs JAM implementations and developer tools.

* [JAM Search](https://search.fluffylabs.dev/)
  Search across JAM documentation, web pages, and community discussions.

* [Gray Paper Reader](https://graypaper.fluffylabs.dev/)
  Read and navigate the Gray Paper online.

* [PVM Debugger](https://pvm.fluffylabs.dev/)
  Inspect, run, and debug PVM programs.

* [JAM Codec](https://codec.fluffylabs.dev/)
  Encode and decode JAM data structures.

* [JAM State Viewer](https://state.fluffylabs.dev/)
  Inspect and analyze JAM state data.

* [Typeberry](https://fluffylabs.dev/typeberry/docs/)
  Fluffy Labs' TypeScript JAM client and API documentation.

## Service Development

* [PolkaVM](https://github.com/paritytech/polkavm)
  PVM-related virtual machine, compilation, and execution tooling.

* [JAM Service Playground](https://playground.jamcha.in/)
  Write and test JAM services in the browser.

* [JAM Examples](https://github.com/tomusdrw/jam-examples)
  JAM service examples and tutorials.

## MiniJAM Resources

* [MiniJAM Playground](https://playground.minijam.xyz/)
  Write, compile, deploy, and test MiniJAM services.

* [MiniJAM Client](https://github.com/ArcheLabs/minijam-client)
  The public MiniJAM client repository.

* [MiniJAM Matrix Room](https://app.element.io/#/room/#minijam:matrix.org)
  Development discussion, testing feedback, and community chat.

## MiniJAM Stage 0

### RPC

```text
wss://rpc-stage0.minijam.xyz
```

Connect with Polkadot.js API or another Polkadot SDK-compatible client.

### Explorer

* [Connect to MiniJAM Stage 0](https://polkadot.js.org/apps/?rpc=wss%3A%2F%2Frpc-stage0.minijam.xyz#/explorer)

Use it to inspect blocks, events, runtime storage, extrinsics, and runtime metadata.
