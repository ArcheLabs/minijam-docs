# Current Status

MiniJAM is an evolving experimental project. Current behavior is defined by the checked-in implementation, deployment configuration, release notes, and passing compatibility tests.

The first documentation phase covers the service execution path, local workers, the SDK, and the Playground. Protocol details that are not implemented or tested are intentionally not presented as stable guarantees.
