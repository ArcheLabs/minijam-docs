# What is MiniJAM?

MiniJAM is an independent experimental network and engineering project inspired by the JAM execution model. It provides a place to develop, run, and inspect services before the complete JAM network is available.

MiniJAM focuses on a practical path from service code through Refine, Work Reports, independent verification, Accumulate, and state changes. It is not the JAM mainnet and does not claim to implement the complete JAM protocol.

For the current boundaries, see [MiniJAM and JAM](./minijam-and-jam.md).
