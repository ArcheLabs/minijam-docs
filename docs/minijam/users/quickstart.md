# User Quickstart

The public entry point is the image-based local development bundle. It requires no Stage 0 credentials.

External users currently cannot build the complete MiniJAM Stack independently from the public source repository.

- Use the hosted Playground: **Not publicly available yet**
- Run locally: [Run MiniJAM locally with Docker](../operators/local-docker.md)

Once the Playground is available, use it to submit a service action and inspect the execution history from Refine through Accumulate. Do not treat `127.0.0.1` as a public Playground address.
